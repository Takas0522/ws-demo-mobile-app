## 4.4 リクエスト処理フロー

### 管理画面リクエスト

```mermaid
sequenceDiagram
    participant B as ブラウザ
    participant F as StrutsFilter
    participant I as AuthInterceptor
    participant A as Action
    participant S as Service
    participant D as DAO
    participant DB as SQLite

    B->>F: HTTP リクエスト
    F->>I: インターセプト
    I->>I: セッション確認
    alt セッションなし
        I-->>B: ログイン画面へリダイレクト
    else セッションあり
        I->>A: Action 実行
        A->>S: ビジネスロジック呼出
        S->>D: データアクセス
        D->>DB: SQL 実行
        DB-->>D: 結果セット
        D-->>S: エンティティ
        S-->>A: 処理結果
        A-->>F: Result（JSP パス）
        F-->>B: HTML レスポンス
    end
```

### REST API リクエスト

```mermaid
sequenceDiagram
    participant C as クライアント
    participant CF as CorsFilter
    participant F as StrutsFilter
    participant J as JwtInterceptor
    participant A as ApiAction
    participant S as Service
    participant D as DAO
    participant DB as SQLite

    C->>CF: HTTP リクエスト
    CF->>CF: CORS ヘッダー付与
    CF->>F: フィルタチェーン
    F->>J: インターセプト
    J->>J: JWT トークン検証
    alt トークン無効
        J-->>C: 401 Unauthorized (JSON)
    else トークン有効
        J->>J: userId/loginId/userType を属性に格納
        J->>A: Action 実行
        A->>S: ビジネスロジック呼出
        S->>D: データアクセス
        D->>DB: SQL 実行
        DB-->>D: 結果セット
        D-->>S: エンティティ
        S-->>A: 処理結果
        A-->>C: JSON レスポンス
    end
```
