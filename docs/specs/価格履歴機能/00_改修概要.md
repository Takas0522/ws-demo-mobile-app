## 3. 現在の実装状況

### 既に実装済みの機能

- `product_price_history` テーブル（DDL・トリガー・インデックス・CHECK 制約）
- 価格変更時の自動履歴記録（DB トリガー `trg_record_price_history`）
- 現行 API: `GET /api/v1/products-price-history?productId=xxx`
- `ProductPriceHistoryDao.findByProductId()` / `ProductService.getPriceHistory()`

### 未実装の機能（設計書で新規に要求）

- パスパラメータ方式の新エンドポイント
- 日付範囲フィルタリング（`startDate` / `endDate`）
- ページネーション（`page` / `limit`）
- レスポンスの `changedBy` オブジェクト化（userId + userName）
- `pagination` オブジェクトの返却
- BFF 転送エンドポイント
- データ保持ポリシー（5 年間、定期バッチ削除）
